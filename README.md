## 一、产品定位

面向**中国大陆理财完全小白的大学生**的资产管理模拟教学网页。用户在虚拟环境里经历"开户认知 → 风险自评 → 模拟操作 → 复盘成长"的完整链路，进入真实市场后能迅速上手。

**核心价值主张**：
- **仿真**：交易流程、费率、T+1、净值确认等规则跟真实App高度一致
- **教学**：任务式带练，每一步告诉用户"在哪、做什么、为什么"
- **零门槛**：从"什么是货币基金"讲起，逐步引导到组合投资

## 五、核心设计亮点

### 资产池（10只）
- 货币基金（R1）→ 债券基金（R2-R3）→ 指数基金（R3-R4）→ 行业主题（R4）→ QDII（R4）→ 黄金（R3）
- 完整联动矩阵：资产间相关性参数支撑"分散投资"教学

### 剧本模式
- **剧本A「牛市的味道」**：体验贪婪，60日
- **剧本B「第一次大跌」**：直面恐惧，90日（核心剧本）
- **剧本C「漫长的横盘」**：熬的修行，120日
- **剧本D「环球同此凉热」**：跨市场分散，60日
- **剧本E「毕业大考」**：综合考验，150日

### 教学六阶段
0. 认识钱（财务快照）
1. 搞定"活钱"（第一次交易：货币基金）
2. 认识波动（债券基金 + 回撤体验）
3. 摸清自己（风险测评10题 → 五档画像）
4. 第一次组合投资（按画像配置 + 剧本A）
5. 直面波动（剧本B/C/D + 画像验证）
6. 进入真实市场（开户指南 + 剧本E毕业考）

### 视觉设计
- **马卡龙精调版**：温柔绿+粉调红，跳出红涨绿跌争议
- **设计 Token 系统**：颜色/字体/间距/圆角/阴影统一管理
- **资产分类色**：每类资产固定颜色，形成视觉记忆
