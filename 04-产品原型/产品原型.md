# 产品原型（信息架构）· v1

> 文字版原型：页面清单、每页放什么、怎么跳转。桌面优先设计、移动端适配（大学生主力是手机，但第一版开发按桌面做，移动适配列入待办）。

**最后更新**: 2026-09-16

---

## 〇、全局结构

**导航模式**：顶部主导航（4个入口）+ 底部无导航（桌面网页惯例）

```
┌─────────────────────────────────────────┐
│  LOGO  │ 总览 │ 市场 │ 学习 │ 剧本        │
└─────────────────────────────────────────┘
```

**全局常驻元素**：
- 右上角：虚拟本金余额（货币式显示，如 ¥100,000.00）
- 首次进入任意页面时：六阶段进度条（横向，常驻在总览页顶部，其他页收进LOGO点击）

**页面总量**：8类页面。用户动线设计成——**所有页面都能在2次点击内到达买入**。

---

## 一、页面清单与内容

### P1 · 首页/总览（用户每次打开看到的第一个页面）

**用途**: 资产总览 + 教学进度 + 行情速览，一屏回答"我的钱怎么样了"

**内容块**（从上到下）:
1. **资产总览卡**（视觉主角，text-hero字号）
   - 总资产大数字（虚拟本金+持仓市值）
   - 总收益额 + 总收益率（positive/negative 语义色）
   - 今日变动（"今日 +35.20"）
   - 迷你走势图（近30日，资产分类色）
2. **六阶段进度条**（横向六节点，当前阶段高亮+名称，点击进学习页）
3. **持仓饼图**（按资产分类色分块，点击跳持仓明细）
4. **市场速览条**（横向滚动：沪深三百/黄金/环球科技 今日涨跌，点击跳对应资产详情）
5. **待办提醒**（如"你的买入申请将于明日确认""剧本B已解锁"）

**跳转**: 持仓明细 / 学习页 / 资产详情 / 剧本页

---

### P2 · 市场页（资产列表）

**用途**: 模拟盘的"货架"，10只资产全在这里

**内容块**:
1. **分类Tab**: 全部 / 稳健（货币+债券）/ 股票（指数+行业）/ 全球（QDII+黄金）
2. **资产卡片列表**（每只一张，含:）
   - 名称 + 风险等级徽章（R1-R5，用warning色阶区分）
   - 类别色条（左侧竖条，asset分类色）
   - 近1年收益率（语义色）
   - 净值/7日年化（货币基金显示后者）
   - 迷你走势图（3个月）
   - 教学标记（"适合你当前阶段"小标签，基于用户进度）
3. **排序**: 默认按风险等级升序（新手先看到稳的——产品价值观的又一次无声表达）

**跳转**: 点击卡片 → P3资产详情

---

### P3 · 资产详情页（每只资产一个，仿真度最高的页面）

**用途**: 复刻真实App的基金详情页，用户在这里做买入决策

**内容块**:
1. **头部**: 名称、风险等级、类别、一句话简介
2. **核心数据区**（大字号）: 近1年收益 / 近3月 / 今年以来；货币基金则显示7日年化+万份收益
3. **走势图**: 时间Tab（1月/3月/1年/剧本全程），下方"对比沪深300"开关——开启后双线对比
4. **阶段涨幅对比表**: 本基金 vs 同类平均 vs 沪深300（真实App标配）
5. **买入/定投按钮**: 底部双按钮，主按钮（brand-accent）"买入"，次按钮"定投"
6. **交易规则折叠区**: 费率表（申购/赎回分档）、T+N、到账时间
7. **运作费用折叠区**: 管理费/托管费/销售服务费 + 一句教学注解（"这些费用每天从净值里扣，你不用另付"）
8. **基金档案折叠区**: 成立时间、规模、经理（字母代号/指数团队）、对比基准
9. **现实指引卡**（页面底部，品牌粉色调）: "这类产品现实中对应：XXX。本页数据为模拟数据" + 免责声明

**跳转**: 买入 → P4交易流程

---

### P4 · 交易流程（买入/卖出/定投共用，多步弹窗而非独立页面）

**流程**（买入为例，每步一屏，可回退）:
1. 输入金额（显示: 可用资金、预计费用、费率）
2. 交易确认页（显示: 按今日/明日净值、T+N确认、费率明细）
3. 首次买该类产品 → 风险测评匹配检查（不匹配则弹提示，允许继续但记录）
4. 提交成功页（"买入申请已提交，预计X月X日确认份额"）
5. 首次买该类资产 → 首次买入教学弹窗（资产池设定.md里每只资产的文案）

**卖出流程**: 输入份额（显示持有天数→对应赎回费率）→ 确认（"持有不足7天将收取1.5%惩罚性赎回费"高亮提示）→ 提交
**定投流程**: 金额+周期（周/月）+扣款日 → 确认页（"扣款日遇非交易日顺延"）

---

### P5 · 持仓页（从总览饼图/持仓明细进入）

**内容块**:
1. **持仓列表**: 每只持仓资产一行——名称、持有金额、持有收益（额+率，语义色）、当日变动
2. **单持仓展开**: 持有份额、成本、现价、持有天数、卖出按钮
3. **交易记录Tab**: 全部申赎记录（时间、操作、金额/份额、净值、状态[待确认/已确认/已到账]）
4. **在途交易提示**: 顶部黄条（"你有1笔买入待确认，明日按T日净值成交"——T+1规则的可视化）

---

### P6 · 学习页（六阶段教学主场景）

**内容块**:
1. **阶段地图**（纵向六节点，当前阶段放大）: 每节点显示阶段名+一句话目标+完成状态
2. **当前阶段详情**: 任务清单（已完成✓/进行中/未开始）、每任务点击进入
3. **任务执行区**: 知识卡轮播（每张≤80字+一个动作按钮）→ 任务动作（跳转到对应页面执行）→ 完成回执
4. **跳关入口**: 每阶段底部小字链接"我已了解，跳过本阶段"
5. **知识库入口**: 全部知识卡的历史归档，可搜索

---

### P7 · 剧本页（模拟盘的"游戏模式"入口）

**内容块**:
1. **剧本卡片墙**: 5个剧本+自由模式，每张卡片——剧本名、历史原型、时长（交易日数）、核心情绪标签、解锁状态
2. **剧本进行中态**: 当前交易日（"第38天"）、行情快照、事件弹窗区、速度控制（1x/5x/20x、暂停）
3. **剧本复盘报告页**:（剧本结束后）
   - 你的收益 vs 持有不动 vs 大盘（三线对比图）
   - 行为统计: 换手率、最大回撤、操作时间点标注在K线上（哪天买的哪天卖的，一眼看穿追涨杀跌）
   - 教学卡片（剧本设计.md每剧本的复盘重点）
   - 验证报告（阶段5: 风险画像验证/降档建议）

---

### P8 · 个人设置页（低优先级）

- 风险画像查看/主动调整
- 数据导出（JSON备份/清空重置）
- 关于+免责声明

---

## 二、核心用户动线（三条）

**动线1 · 新用户**: 首页（财务快照引导）→ 阶段0自测 → 开通虚拟账户 → 阶段1任务（买货币基金）→ 次日回访确认 → 进阶段2
**动线2 · 日常用户**: 打开首页 → 看总览/今日变动 → 可能点进持仓看看 → 关掉（"没事别打开"是教学内容，但产品不做硬限制）
**动线3 · 剧本用户**: 学习页阶段4 → 一键买入推荐组合 → 进剧本A → 快进 → 复盘 → 解锁下一剧本

---

## 三、关键交互决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| 导航模式 | 顶部4入口 | 页面类型天然四分（资产/市场/教学/剧本），底部导航是移动App惯例 |
| 市场页默认排序 | 风险等级升序 | 新手先看到R1，货架顺序即教学 |
| 交易流程形态 | 多步弹窗 | 保持"在详情页里"的上下文感，与支付宝一致 |
| 剧本时间控制 | 可调速+暂停 | 用户需要停下来思考，强制快进会毁掉情绪教学 |
| 首页总览占比 | 大数字+迷你图 | "打开就看到钱"是理财App的第一心理需求 |
| 待确认交易 | 顶部黄条常驻 | T+1规则的可视化教学，每天看得到 |
