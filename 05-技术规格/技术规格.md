# 技术规格 · v1（翻译层：设计文档 → AI开发任务书）

> 把四份设计文档拆成有序开发任务。每个任务自包含（附喂给AI的上下文片段）、有验收标准。
> **使用方式**：按顺序逐个任务发给AI coding工具，每个任务完成后人工验收，通过再发下一个。

**最后更新**: 2026-09-16

---

## 〇、总体技术决策

| 项 | 决策 | 理由 |
|---|---|---|
| 形态 | 单页应用（SPA），纯前端 | GitHub Pages 只支持静态托管 |
| 框架 | **Vue 3 + Vite**（组合式API） | AI对Vue3生成质量稳定；比React少JSX心智负担；Vite开箱即用 |
| 图表 | **ECharts** | K线/净值线/饼图/对比图全覆盖，中文文档全 |
| 数据存储 | **localStorage**（Pinia状态管理 + 持久化插件） | 单机单用户，无需后端 |
| UI | 手写CSS（design-tokens.css 变量文件） | 不引组件库——粉彩定制风格用组件库会打架 |
| 部署 | GitHub Pages | 已定 |

**目录结构约定**:
```
src/
├── styles/tokens.css        ← 设计Token落地
├── stores/                   ← Pinia: 资产/持仓/交易/进度/剧本
├── engine/                   ← 行情引擎、剧本引擎、事件系统
├── views/                    ← 8个页面
├── components/               ← 弹窗/卡片/图表封装
└── data/                     ← 资产池/剧本/知识卡/文案（JSON）
```

## 一、任务清单（14个任务，4个阶段）

### 阶段一：骨架（能看不能用）

**T1 · 项目初始化 + 设计Token落地**
- 上下文: `design-tokens.md` 全文
- 要求: 建Vue3+Vite项目；tokens.css 按文档逐项实现（CSS变量命名与文档Token名一致）；首页空壳+顶部导航（4入口，可点击切换占位页）
- 验收: `npm run dev` 后导航可切换4个空白页；控制台无报错；tokens.css 变量可被组件引用

**T2 · 八页面骨架 + 路由**
- 上下文: `产品原型.md` P1-P8 的内容块清单（只要区块名，不要细节）
- 要求: Vue Router 配置8页面；每页按原型的内容块顺序放**灰色占位块**（标注区块名）；总览页顶部进度条占位
- 验收: 从首页出发，所有页面2次点击内可达；每页区块布局与原型文档对应

**T3 · 资产数据层**
- 上下文: `资产池设定.md` 全文
- 要求: 10只资产转为 `data/assets.json`；类型定义（TypeScript interface：身份/行为/交易/费用/教学5组字段）；市场页渲染资产卡片列表（分类Tab+风险排序）
- 验收: 市场页显示10只资产，排序为R1→R4；卡片显示名称/风险徽章/类别色条/近1年收益（先用静态数）

### 阶段二：核心引擎（灵魂）

**T4 · 行情引擎（随机游走）**
- 上下文: 资产池设定.md 的行为参数+联动矩阵
- 要求: 按各资产年化收益/波动/单日限制生成日度涨跌；用联动矩阵实现资产间相关（Cholesky分解或简化：以沪深三百为主因子+各资产beta+特质噪声）；货币基金走万份收益累积逻辑
- 验收: 跑500日模拟，各资产年化收益/波动落在设定区间；黄金与沪深三百负相关可见；货币基金日收益≈0.5元/万

**T5 · 剧本引擎**
- 上下文: `剧本设计.md` 全文
- 要求: 剧本=时间序列数据文件（各资产每日涨幅+事件表）；剧本A/B/C/D/E五份+自由模式（调T4引擎）；时间控制（1x/5x/20x/暂停）；事件按日触发弹窗
- 验收: 剧本A跑通60日，K线与文档主线表趋势一致（±3%内）；事件在正确日期弹出；暂停/调速正常

**T6 · 交易系统**
- 上下文: 资产池设定.md 交易规则 + 产品原型.md P4
- 要求: 买入/卖出/定投三流程；T+1确认（15:00后按次日净值——模拟盘用"快进日"代替时钟）；费率分档计算（赎回<7天1.5%等）；快赎1万限额；待确认/确认中/已到账状态机
- 验收: 买入→次日确认→卖出→费率正确；持有6天卖出收1.5%惩罚费率并高亮提示；黄条显示在途交易

**T7 · 持仓与账户**
- 上下文: 产品原型.md P5
- 要求: 持仓计算（份额/成本/市值/收益）、总览页数据、交易记录、localStorage持久化（刷新不丢）
- 验收: 买入后刷新页面数据完整；总资产=现金+持仓市值，收益计算正确

### 阶段三：教学与体验（血肉）

**T8 · 学习系统（六阶段）**
- 上下文: `教学六阶段.md` 全文
- 要求: 阶段地图+任务清单+知识卡轮播组件；阶段0自测三题→财务快照；跳关机制；知识库归档页
- 验收: 阶段0→1完整走通；跳关后标记"未完成"可回补

**T9 · 风险测评 + 画像**
- 上下文: 教学六阶段.md 阶段3
- 要求: 10题问卷；五档画像计算；推荐配置饼图；第6/7题矛盾检测彩蛋；画像可主动调整（阶段5验证后降档）
- 验收: 测评出画像+配置表；矛盾答案触发彩蛋文案

**T10 · 剧本复盘报告**
- 上下文: 剧本设计.md 各剧本复盘重点 + 产品原型.md P7
- 要求: 三线对比图（你的收益/持有不动/大盘）；行为统计（换手率/最大回撤）；**操作点标注在K线上**；各剧本专属复盘卡片；阶段5验证报告
- 验收: 剧本B通关后报告完整；K线上能看到自己的买卖点

**T11 · 定投系统**
- 上下文: 资产池设定.md（支持定投字段）+ 剧本C定投教学
- 要求: 定投计划创建/暂停/终止；剧本快进时按扣款日执行；定投vs一次性对比图（剧本C第50日弹）
- 验收: 剧本C中创建月定投，扣款日遇非交易日顺延；对比图数据正确

**T12 · 教学弹窗系统**
- 上下文: 资产池设定.md 首次买入文案 + 教学六阶段.md 各任务提示
- 要求: 首次买入弹窗（按资产去重）；剧本事件弹窗（新闻/震动提示/诱惑事件分级样式）；震动提示与普通新闻视觉区分
- 验收: 每只资产首次买入弹对应文案，第二次不弹

### 阶段四：收尾（毕业与上线）

**T13 · 毕业大考 + 通关判定**
- 上下文: 剧本设计.md 剧本E + 教学六阶段.md 阶段6
- 要求: 剧本E三幕拼接+人性诱惑事件随机池（去重）；四项行为标准判定（顶部加仓检测/底部全割检测/杠杆内幕接触/换手率阈值）；毕业证书页；阶段6知识模块（开户指南/渠道对比/防割清单——静态图文页）
- 验收: 剧本E通关判定正确；故意乱操作的用户拿不到毕业证

**T14 · 打磨与部署**
- 上下文: design-tokens.md + 全局走查
- 要求: 移动端适配（P1/P3/P7重点）；数据导出/清空重置（P8）；免责声明（首页底部+详情页"模拟数据"标识）；`vite.config.js` 配置 base 路径 → build → GitHub Pages 部署
- 验收: 手机宽度可正常使用；线上URL可访问

## 三、验收总原则（每个任务通用）

1. 每任务完成后**亲自点一遍**该任务的所有验收点，不通过就带着具体现象回给AI修
2. 每任务通过后 `git commit` 一次（commit信息=任务号+名称），出问题能回滚
3. 修bug时只给bug上下文+相关代码段，不重发全项目
